## 格式要求

| 类型      | 格式                   | 大小限制              |
| --------- | ---------------------- | --------------------- |
| 图片      | JPG / WebP             | ≤500KB（大图 ≤1MB）   |
| Logo/封面 | PNG / SVG              | ≤200KB                |
| Favicon   | ICO                    | ≤50KB                 |
| 视频      | MP4（H.264）           | ≤20MB                 |
| 动图      | GIF（建议后续转 MP4）   | ≤2MB                  |

> 全站已使用 **60 个图片文件**（JPG + WebP 双格式），覆盖 SVG、ICO 格式；工厂流程区保留少量 GIF 动图，后续可按性能优化计划转 MP4。
>
> **图片交互说明**：所有需要悬停放大效果的图片均包裹在 `.img-wrap` 容器内，并配合 `.h-full` / `picture` 占满容器。CSS 在悬停时将图片放大至 `scale(1.04)`，过渡 0.4s，容器 `overflow:hidden` 保证放大不溢出圆角。
>
> **设计模式说明**：含多变体的产品（Field Fence、Y Post）使用「变体选择卡片 + 三列等高画廊」交互模式。点击变体卡片后，画廊带方向滑动动画切换（左进左出/右进右出）。Field Fence 分为拧编（Hinge Joint）和环扣（Ring Lock）两组画廊，Y Post 分为 Studded / Plain / Scalloped 三种类型。所有页面内主要图片不重复使用，每个场景使用独立素材。
