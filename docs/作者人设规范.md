## 2. Person JSON-LD 标准模板

文章页 `BlogPosting.author` 必须使用 `Person`（禁止再用 Organization 署名）：

```json
"author": {
  "@type": "Person",
  "@id": "https://lianjiafence.com/#vera",
  "name": "Vera Sun",
  "jobTitle": "Co-Founder",
  "worksFor": { "@id": "https://lianjiafence.com/#organization" }
}
```

`publisher` 保持引用 `"@id": "https://lianjiafence.com/#organization"`。

## 3. About 区块简介卡

首页 About 区块包含三人简介卡，每人带 `Person` schema，锚点 id 分别为 `vera` / `leo` / `david`（首页 `#about` section 内），与文章 `@id` 对应。
