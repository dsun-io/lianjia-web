# 图片与图标规范

> 目标：全站图片体积可控、格式统一、favicon 完整。压缩是破坏性操作，必须先备份。

---

## 1. 图片分级压缩标准

| 级别 | 判定（文件名含） | 宽度上限 | 体积上限 | 质量 |
|------|----------------|---------|---------|------|
| Hero | `hero`、`app-` | 1600px | 180KB | WebP q80 / JPG q82 |
| 内容图 | 其他 jpg/webp | 1200px | 150KB | WebP q80 / JPG q82 |
| 缩略图 | `thumb`、`type-` | 800px | 80KB | WebP q75 / JPG q78 |
| logo/icon | `logo`、`favicon` | 不缩放（按源） | — | PNG 无损 |

**规则**：
- 文件名与格式保持不变（`.jpg` 仍是 `.jpg`，`.webp` 仍是 `.webp`），HTML 零改动。
- 只处理超过上限的文件；未超标的文件不动。
- 已超宽的图先缩到宽度上限再压质量。

## 2. 压缩 SOP（必须按序执行）

```powershell
npm run backup:images   # 备份 assets/img → 素材/img-backup/（已存在则跳过）
npm run optimize:images # node optimize-images.js
node check-assets.js    # 校验全站引用完整性
```

- 压缩后若视觉效果不可接受：从 `素材/img-backup/` 复制回对应文件还原。
- 新增图片入库前必须跑 `optimize:images`，并在 `check-assets.js` 通过后才能提交。

## 3. Favicon 规格

源图：方形粗边框款 logo（`素材/logo/cd0c349dc641689fe23a5cf316d13c41.jpg`，深蓝圆角方形图标：左焊接网格 + 右链环纹，白底无文字）。**注意**：本款为浏览器标签页/搜索结果 favicon 的选定款（2026-08 用户确认）。

| 文件 | 尺寸 | 用途 |
|------|------|------|
| `/favicon.ico` | 16/32/48 多尺寸合一 | 浏览器标签页、搜索结果列表图标 |
| `/assets/img/favicon-48.png` | 48×48 | 常规 PNG icon |
| `/apple-touch-icon.png` | 180×180 | iOS 主屏 |
| `/assets/img/favicon-192.png` | 192×192 | Android / PWA |
| `/assets/img/favicon-512.png` | 512×512 | PWA splash |

HTML 引用组（全站统一，见前端组件规范第 4 节）：

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="48x48" href="/assets/img/favicon-48.png">
<link rel="icon" type="image/png" sizes="192x192" href="/assets/img/favicon-192.png">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

**背景处理**：favicon 使用与 logo 一致的深蓝 `#1B3A6B` 图标 + 白底；apple-touch-icon 必须为不透明底（iOS 不支持透明）。
