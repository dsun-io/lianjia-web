Installation Guide

How to Install Chain Link Fence

1

Layout & Set Posts

Mark the fence line. Install terminal (end/corner) posts first — dig to 1/3 of post height, set in concrete. Then add line posts at 2.5–3 m intervals.

2

Install Rails & Tension Wire

Attach top rail or tension wire between terminal posts. Add bottom tension wire along the ground line for stability.

3

Stretch & Hang the Mesh

Unroll chain link along the fence line. Use a come-along and stretcher bar to tension the mesh evenly. Tie to top rail and line posts with wire ties every 300–400 mm.

4

Secure & Finish

Fasten mesh to terminal posts with tension bands. Trim excess wire. Install caps on all post tops. For barbed top selvage, angle outward for added security.

Pro Tip

Always stretch chain link mesh from the bottom up — this prevents the diamond pattern from distorting. For slopes, step the mesh in sections rather than racking it.
